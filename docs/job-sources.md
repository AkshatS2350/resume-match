# Permitted job sources

ResumeMatch v1 permits only the following sources. LinkedIn and Indeed scraping
are not permitted, nor is HTML scraping of a site whose terms prohibit automated
access.

| Source | Documentation |
| --- | --- |
| Greenhouse | https://developers.greenhouse.io/job-board.html |
| Lever | https://github.com/lever/postings-api |
| Ashby | https://developers.ashbyhq.com/docs/public-job-posting-api |
| Adzuna | https://developer.adzuna.com/ |
| USAJobs | https://developer.usajobs.gov/ |
| Fixture | fixture://checked-in |
