# 0007 — Reference role catalogue

Status: accepted

OD-01 is resolved. The five architecture-validation reference roles are:

- Backend Engineer — Intern / New Grad (`backend_engineer`)
- Financial Analyst — Entry
- Embedded Software / Firmware Engineer — Intern / Entry
- Performance Marketing Analyst — Entry (`performance_marketing_analyst`)
- Supply Chain Analyst — Entry

They validate one generic Role_Rubric and scoring architecture. They are not a closed product catalogue. Additional explicitly tasked rubrics may be shipped as schema-conforming configuration with the same deterministic scoring path; their validation status must be exposed to users. `draft` is permitted, while `reviewed` and `stable` require the documented validation process.
