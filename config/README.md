# Configuration

This directory contains version-controlled, declarative behavior. Every configuration
file carries a `version` key that is echoed in applicable responses.

Planned files: `evidence_multipliers.yaml`, `confidence_weights.yaml`,
`match_weights.yaml`, `match_penalties.yaml`, `match_thresholds.yaml`,
`disqualification.yaml`, `relevance_rule.yaml`, `pii_policy.yaml`,
`pii_placeholders.yaml`, `requirement_patterns.yaml`, `delimitation_rules.yaml`,
`seniority_mapping.yaml`, `role_family_equivalence.yaml`,
`company_domain_mapping.yaml`, `candidate_context_resolver.yaml`, `quantity_units.yaml`, `proficiency_exclusions.yaml`,
`dimension_match_scoring.yaml`, `section_headings.yaml`, `llm_budget_priority.yaml`, and `source_registry.yaml`.
